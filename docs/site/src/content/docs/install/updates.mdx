The desktop app updates itself. Open **Settings → Updates** in the app, or choose
**Check for updates…** in the tray menu.

## Channels

| Channel | What it installs | Needs |
|---|---|---|
| **Stable** (default) | The latest [GitHub release](https://github.com/Mark7888/two-place-paste/releases/latest). | Nothing. |
| **Beta** | The newest build of the main branch. | Nothing. |
| **Nightly** | The build of one specific commit, from GitHub Actions. For testing a fix. | A GitHub fine-grained token with *Actions: Read-only* on this repository. It is kept in your keychain or DPAPI store. |

The relay server has matching image tags: `latest` for Stable and `beta` for Beta. See
[Docker image tags](/two-place-paste/self-hosting/docker/#image-tags).

## How it behaves

- With **Install updates automatically** on, the app checks about every six hours. On macOS it lets
  the system pick the time and holds off on battery and in Low Power Mode.
- An update only restarts the app when the screen is locked or nothing has synced for ten minutes,
  so it never interrupts you mid-copy.
- While a build downloads, Settings → Updates shows how far it has got. A slow connection is fine:
  the download only gives up if nothing arrives for a minute, and then says so; press
  **Install and restart** again to retry.
- Every download is checked against a manifest signed in CI. A build that does not match is not
  installed.
- The previous version is kept, and **Roll back to …** in Settings → Updates returns to it in one click.
- When you install an update (or roll back) from Settings → Updates, the app restarts and opens in a
  new browser tab with a note saying which version it is now running. An automatic update restarts
  quietly into the tray and opens nothing.
- A page left open after the app quits or restarts can no longer reach it, and says so: *TwoPlacePaste
  was closed or restarted*. The message cannot be dismissed; use the new tab, or open the app again
  from the tray icon, and close the old one.

<Aside>
	A build you compiled yourself (version `0.0.0-local`) never replaces itself.
</Aside>
