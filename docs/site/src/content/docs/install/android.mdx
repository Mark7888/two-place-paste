<Aside type="note">
	The Android app is in development and is not documented yet. Its debug builds appear on the
	[releases page](https://github.com/Mark7888/two-place-paste/releases), but they are not ready
	for everyday use.
</Aside>

It uses the same groups, relay and encryption as the desktop app, so a phone will join your
existing group like any other device.
