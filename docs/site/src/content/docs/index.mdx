<CardGrid>
	<Card title="End-to-end encrypted" icon="padlock">
		Every entry is encrypted on your device before it leaves. The relay stores ciphertext, sizes
		and timestamps — never content, type or filename.
	</Card>
	<Card title="Yours to host" icon="seti:docker">
		One Go binary and one Redis. Run the published Docker image behind your reverse proxy in a few
		minutes.
	</Card>
	<Card title="Nothing lingers" icon="clock">
		Every entry expires after 24 hours. Revoking a device rotates the group key, so it cannot read
		anything written afterwards.
	</Card>
	<Card title="Text, images and files" icon="document">
		Up to 50 MB per entry. Sync on demand, or let the app watch the clipboard for you.
	</Card>
</CardGrid>
