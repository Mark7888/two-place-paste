title: Add a device
description: Pair another computer with your group, in whichever direction is easier.
---

Adding a device means a device that is **already in the group** hands the group key to the
**new device**. It works in either direction — pick whichever device has the screen the other one
can read. Either way, the code is a QR code and the same text with a **Copy** button.

<Tabs>
<TabItem label="The member shows a code">

Use this when the new device can scan or paste.

<Steps>

1. On a device **already in the group**, open **Pairing** and press **Show pairing code**.

   <Image src={code} alt="The Pairing tab showing a pairing QR code and link" class="screenshot" />

   The code works once and expires after 5 minutes.

2. On the **new device**, open **Pairing**, paste the code into **Join a group** and press **Join**.
   It shows its own **fingerprint** below the button and waits.

3. Back on the first device, a dialog asks whether to add the new device. It names it and shows
   its fingerprint. **Press Add only if the fingerprint matches the one the new device shows**;
   otherwise press **Turn it down**.

   <Image src={joinRequest} alt="A dialog asking whether to add Pixel 9, with its fingerprint" class="screenshot" />

   The dialog appears whichever tab is open. On Android it is a sheet above every screen, and the
   new device's fingerprint is on its setup screen.

</Steps>

<Aside type="caution">
	The new device's key reaches the first device through the relay, so this check is what stops a
	relay from slipping in a device of its own. If the fingerprints do not match, something other
	than your device answered the code.
</Aside>

</TabItem>
<TabItem label="The new device shows a code">

Use this when the **member** is the one that can read a code — for example a phone scanning a
desktop that is not in the group yet.

<Steps>

1. On the **new device**, open **Pairing → Show a code instead**. Type the relay's address
   (for example `https://tpp.example.com`) and press **Show a code**.

2. On a device **already in the group**, open **Pairing**, paste the code under
   **Accept a code from a device with no group** and press **Connect**.

3. Check the dialog. It names the new device and shows a fingerprint of its key. **Confirm only if
   the fingerprint matches the one the new device shows.**

</Steps>

<Aside type="caution">
	This confirmation matters. Confirming hands that device the group key — if the fingerprint does
	not match, someone else's device is asking to join.
</Aside>

</TabItem>
</Tabs>

A device syncs with one group at a time. To move it to another group, use
**Settings → Leave the group** first, or keep several groups and switch between them: see
[Several groups](/two-place-paste/guides/groups/).
