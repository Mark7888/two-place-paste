TwoPlacePaste lives in the system tray on Windows and in the menu bar on macOS. The icon is a small
clipboard that changes to show what the app is doing.

| Icon | Meaning |
|---|---|
| <TrayIcon state="connected" alt="Connected" /> | **Connected** to the relay and idle. |
| <TrayIcon state="connecting" alt="Connecting" /> | **Connecting** — faded while the connection comes up. |
| <TrayIcon state="uploading" alt="Uploading" /> | **Uploading** an entry (↑). |
| <TrayIcon state="downloading" alt="Downloading" /> | **Downloading** an entry (↓). |
| <TrayIcon state="syncing" alt="Uploading and downloading" /> | **Both at once** (⇅). |
| <TrayIcon state="disconnected" alt="Disconnected" /> | **Disconnected** — struck through. It keeps retrying on its own. |
| <TrayIcon state="unpaired" alt="Not paired" /> | **Not paired yet** — faded and empty. Open the app to [create](/two-place-paste/guides/create-a-group/) or [join](/two-place-paste/guides/add-a-device/) a group. |
| <TrayIcon state="paused" alt="Auto-sync paused" /> | **Auto-sync paused** — the pause badge. Nothing is uploaded or downloaded on its own until the pause ends. See [Pausing auto-sync](/two-place-paste/guides/sync/#pausing-auto-sync). |
| <TrayIcon state="skipped" alt="Needs attention" /> | **Needs a look** — the **!** badge. An automatic upload or download was held back by your [size limit](/two-place-paste/guides/settings/#automatic-size-limits), or failed. It clears at the next sync or when you dismiss the notice in the app. |

Hovering the icon shows the same state in words, after the group's name — the name whoever runs the
relay gave it. The app's window shows that name in its title bar too.

## The menu

| Item | What it does |
|---|---|
| *(status line)* | The state above, in words. |
| **Sync now** | Syncs in whichever direction is newer — see [Syncing](/two-place-paste/guides/sync/). |
| **Upload this clipboard** / **Download the latest** | Appear for a few minutes after **Sync now** could not tell which way to go. |
| **Pause auto-sync for 5 minutes** / **Resume auto-sync (paused until …)** | One item: pauses both automatic directions for five minutes, and while paused, ends the pause. Greyed out when neither *Watch the clipboard* nor *Take what other devices upload* is on. |
| **Push protected entry anyway** | Appears for two minutes after a sync from the tray would have uploaded a [sensitive copy](/two-place-paste/guides/sensitive-content/). The same question also arrives as a notification with a **Push anyway** button. |
| **Open TwoPlacePaste** | Opens the app in your browser. Starting the app again while it runs (from the Start menu, Launchpad or a double-click) does the same. |
| **Check for updates…** | Checks your [update channel](/two-place-paste/install/updates/). |
| **Quit** | Stops the app. Nothing syncs until you start it again. |

If the app cannot start its window — usually because its port is taken — the menu says
**TwoPlacePaste could not start**, shows the reason, and offers **Open the settings file…** so you
can change the port. See [Troubleshooting](/two-place-paste/guides/troubleshooting/#the-tray-says-twoplacepaste-could-not-start).
