## Behaviour

| Setting | Default | What it does |
|---|---|---|
| **Watch the clipboard** | Off | Anything you copy is encrypted and uploaded as the group's newest entry. |
| **Take what other devices upload** | Off | A new entry from another device replaces this clipboard as soon as it arrives. |
| **Start at login** | Off | Starts the app when you log in. A launchd agent on macOS, a `Run` registry entry for your user on Windows. |

## Automatic size limits

| Setting | Default | What it does |
|---|---|---|
| **Upload automatically up to** | 25 MB | The largest copy *Watch the clipboard* uploads on its own. |
| **Download automatically up to** | 25 MB | The largest entry *Take what other devices upload* downloads on its own. Decided before downloading. |

Leave a field empty for no limit. Anything over a limit waits for you: send it with **Upload**, or
fetch it with **Download** or [History](/two-place-paste/guides/history/) — those are never
limited. A notice at the top of the app (and a **!** on the [tray icon](/two-place-paste/guides/tray/))
says what was held back, until you dismiss it or the next entry moves.

## Sensitive content

| Setting | Default | What it does |
|---|---|---|
| **Detect password managers and private copies** | On | A copy its app marks as private — a password manager's, most often — is not uploaded automatically, and **Upload** asks before sending it. |
| **Filters** | Private keys only | Your own filters and the built-in detectors. The line shows how many are on; **Edit…** opens the filter editor. |

See [Sensitive content](/two-place-paste/guides/sensitive-content/) for what each detector and
filter kind matches.

## This device

| Setting | Default | What it does |
|---|---|---|
| **Name** | The computer's name | What your other devices show for this one, for example in the revoke dialog. Applies at the next launch. |
| **Localhost port** | 47821 | The port of the app's own page, on `127.0.0.1`. Change it if another program uses 47821. Applies at the next launch. |

This section also shows where the keys are kept: the macOS keychain or a DPAPI-sealed file on
Windows.

## Updates

Channel, automatic updates and rollback — see [Updates](/two-place-paste/install/updates/).

## Leave the group

Disconnects this device and **deletes its keys** — both its own private key and the group key —
and returns the app to its setup screen with a new identity. Use it to move a computer to a
different group.

<Aside type="caution">
	Leaving is local only. The relay still lists this device in the group. To make sure it cannot
	read anything written later, [revoke it](/two-place-paste/guides/devices/) from another device.
</Aside>

## The settings file

Settings are stored as plain JSON in `desktop.json`, so you can edit it by hand — for example to
fix the port when the app cannot start. It holds no keys. Your sensitive-content filters are in it
as you typed them, except an *Exact match*, which is stored only as a hash.

| OS | Location |
|---|---|
| Windows | `%APPDATA%\TwoPlacePaste\desktop.json` |
| macOS | `~/Library/Application Support/TwoPlacePaste/desktop.json` |
